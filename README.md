# jarvis-collab

A shared co-development environment for Sonny's Jarvis (JarvisLinux) and Corey's Jarvis.

## Purpose
Co-create agents, skills, and tools that both Jarvis instances can use.

## Instances
- **JarvisLinux** (Sonny) — `sonny-jarvis.tailc64612.ts.net`
- **Jarvis** (Corey) — `100.81.163.32`

## Structure
- `skills/` — shared OpenClaw skills
- `agents/` — shared agent configs
- `schema/` — task envelope + result schemas
- `PROTOCOL.md` — co-dev comms protocol

## Quick Start
Both instances clone this repo and install skills from `skills/`.
